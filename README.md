# Workout-Tracker-App
An application for tracking workouts, exercises and progress over time.

## Features (Included)
- Track workouts by date
- Select muscle groups for a day (chest, back, etc.)
- Under each muscle group, track which exercises you are doing
- Record individual sets, reps, and weight
- Save sets under exercises and show saved sets
- Have a past performances for each exercise that shows the most recent saved sets, not including those on that same day
- Automatic file saving whenever the user selects to close the application, and automatic file loading so previous
workout data is shown
